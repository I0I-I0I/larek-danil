# Подробное руководство по запуску проекта Larek для новичков

Привет! Это пошаговое руководство поможет тебе запустить проект **Larek** (интернет-магазин с фронтендом на React и бэкендом на Node.js + SQLite), даже если ты никогда раньше не занимался программированием.

Проект состоит из двух частей:
1. **Фронтенд (Frontend)** — визуальная часть сайта (кнопки, товары, корзина), которую видит пользователь.
2. **Бэкенд (Backend)** — серверная часть, которая управляет базой данных товаров, пользователями и заказами.

Мы рассмотрим два способа запуска. Выбирай тот, который тебе удобнее!

---

## 📊 Сравнение способов запуска

| Характеристика | Способ 1: Через Docker (Рекомендуемый ⭐️) | Способ 2: Локально (Node.js + pnpm) |
| :--- | :--- | :--- |
| **Сложность** | **Очень легко** (всё настраивается само) | **Средняя** (нужно установить Node.js и библиотеки) |
| **Требования** | Нужен только Docker Desktop | Нужен Node.js, компилятор C++ (для БД) и pnpm |
| **Для кого** | Идеально для абсолютных новичков | Для разработчиков, которые хотят править код |
| **Стабильность** | Высокая (не зависит от твоей ОС) | Зависит от настроек твоей операционной системы |

## 🛠️ Что такое «Терминал» / «Консоль»?

Перед тем как начать, тебе часто придется открывать терминал (командную строку) для ввода команд.
* **На Windows**: Нажми клавишу `Win`, введи `PowerShell` или `cmd` (Командная строка) и нажми Enter. Также можно использовать встроенный терминал в редакторе кода (например, VS Code).
* **На Linux / WSL**: Открой приложение `Terminal`.

> [!NOTE]
> Все команды в руководстве нужно вводить в терминал по очереди и нажимать **Enter**. Символ `$` в начале команд писать **не нужно** — он просто показывает начало строки в терминале.

## 🐳 Способ 1: Запуск через Docker (Самый простой и быстрый)

Docker — это программа, которая создает изолированный «контейнер» (мини-компьютер внутри твоего ПК) со всеми установленными программами. Тебе не придется настраивать базы данных или устанавливать Node.js.

### Шаг 1. Установка Docker
* **Windows**:
  1. Скачай [Docker Desktop для Windows](https://www.docker.com/products/docker-desktop/).
  2. Запусти установщик. Убедись, что галочка **«Use WSL 2 instead of Hyper-V»** включена (это стандартная опция).
  3. После установки перезагрузи компьютер, если этого потребует программа.
  4. Запусти Docker Desktop и дождись, пока иконка в левом нижнем углу станет зеленой.
* **WSL (Windows Subsystem for Linux)**:
  1. Установи Docker Desktop на Windows (как описано выше).
  2. Зайди в настройки Docker Desktop (шестеренка вверху) -> **Resources** -> **WSL integration**.
  3. Включи переключатель для твоего дистрибутива (например, `Ubuntu`) и нажми **Apply & restart**. Теперь Docker будет доступен внутри WSL!
* **Linux (Ubuntu / Debian)**:
  Открой терминал и выполни следующие команды для установки Docker и Docker Compose:
  ```bash
  sudo apt update
  sudo apt install -y docker.io docker-compose-v2
  # Разрешаем запускать docker без sudo (потребуется перезайти в сессию):
  sudo usermod -aG docker $USER
  ```

### Шаг 2. Запуск проекта
1. Открой терминал и перейди в папку с проектом. Например:
   ```bash
   cd /путь/к/папке/danil
   ```
2. Запусти сборку и старт проекта одной командой:
   ```bash
   docker compose up --build
   ```
   > [!IMPORTANT]
   > При первом запуске Docker скачает необходимые компоненты и скомпилирует проект. Это может занять от 2 до 5 минут. Пожалуйста, подожди. В консоли побегут логи бэкенда и фронтенда.

### Шаг 3. Проверка работы
Когда в консоли появятся строчки о готовности, открой браузер и перейди по адресу:
👉 **[http://localhost:8080](http://localhost:8080)**

Всё! Сайт готов к работе. База данных автоматически создастся и наполнится тестовыми товарами.

### Как остановить проект?
Чтобы остановить проект, в окне терминала, где запущен Docker, нажми комбинацию клавиш **`Ctrl + C`**.
Или открой новое окно терминала в этой же папке и введи:
```bash
docker compose down
```

## 💻 Способ 2: Запуск локально без Docker (для разработки)

Если ты хочешь запускать проект напрямую на своем компьютере, тебе нужно будет установить среду выполнения **Node.js** и менеджер пакетов **pnpm**.

### Шаг 1. Подготовка окружения (Установка Node.js и pnpm)

#### 🪟 Инструкция для Windows
1. Перейди на официальный сайт [Node.js](https://nodejs.org/) и скачай версию **LTS** (например, Node 20 или Node 22). Запусти установщик.
2. В процессе установки обязательно оставь галочку **«Automatically install the necessary tools...»** (это установит Chocolatey и инструменты сборки C++, которые нужны для работы базы данных SQLite).
3. После завершения установки открой **PowerShell** от имени Администратора и установи менеджер пакетов `pnpm` командой:
   ```powershell
   npm install -g pnpm
   ```

#### 🐧 Инструкция для Linux / WSL
Открой терминал и установи Node.js с помощью менеджера версий NVM (Node Version Manager):
1. Установи NVM:
   ```bash
   curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
   ```
2. Закрой и снова открой терминал (или выполни `source ~/.bashrc`).
3. Установи Node.js:
   ```bash
   nvm install --lts
   ```
4. Установи инструменты сборки (они необходимы для компиляции базы данных SQLite):
   ```bash
   sudo apt update
   sudo apt install -y build-essential python3
   ```
5. Установи `pnpm`:
   ```bash
   npm install -g pnpm
   ```

---

### Шаг 2. Установка зависимостей проекта

Проект разделен на две части, поэтому нам нужно установить библиотеки отдельно для бэкенда и для фронтенда.

1. Открой терминал в корневой папке проекта (`danil`).
2. Перейди в папку бэкенда и установи библиотеки:
   ```bash
   cd backend
   pnpm install
   ```
3. Вернись обратно и перейди в папку фронтенда для установки библиотек:
   ```bash
   cd ../frontend
   pnpm install
   ```

---

### Шаг 3. Запуск проекта

Для полноценной работы приложения тебе нужно запустить **одновременно** и сервер (бэкенд), и интерфейс (фронтенд). Для этого тебе понадобятся **два отдельных окна терминала**.

#### Окно 1: Запуск сервера (Backend)
1. Открой первый терминал в папке проекта.
2. Перейди в папку бэкенда:
   ```bash
   cd backend
   ```
3. Запусти сервер:
   ```bash
   node server.js
   ```
   В консоли должно появиться сообщение:
   `Backend listening at http://localhost:3000` и `Failed to initialize database: ...` (если возникнут проблемы) или успешный старт базы данных.

#### Окно 2: Запуск интерфейса (Frontend)
1. Открой второй терминал в папке проекта.
2. Перейди в папку фронтенда:
   ```bash
   cd frontend
   ```
3. Запусти сервер разработки:
   ```bash
   pnpm dev
   ```
   В консоли появится адрес для открытия сайта, обычно это:
   👉 **[http://localhost:5173](http://localhost:5173)**

Открой эту ссылку в браузере. Фронтенд автоматически настроен перенаправлять запросы к серверу на порт `3000` благодаря конфигурации в [vite.config.js](file:///home/nnofly/code/work/danil/frontend/vite.config.js).

## ❓ Часто задаваемые вопросы и ошибки

### 1. Ошибка при установке библиотек (better-sqlite3 / bcrypt)
* **Причина**: Эти библиотеки написаны на C++ и требуют компиляции под твою операционную систему.
* **Решение**: Убедись, что ты установил инструменты сборки (`build-essential` на Linux/WSL или VS Build Tools на Windows). Если не получается это сделать — используй **Способ 1 (Docker)**, там всё скомпилируется автоматически внутри контейнера.

### 2. Порт уже занят (Port already in use)
* **Причина**: Какая-то другая программа на твоем компьютере использует порт `3000` или `8080`.
* **Решение**: Закрой программы, которые могут использовать сеть (например, другие запущенные проекты, Skype или базы данных), либо перезагрузи компьютер.

### 3. Где хранятся данные?
* База данных SQLite представляет собой файл `larek.db`.
* При работе через Docker она сохраняется в специальном защищенном хранилище (volume) под названием `backend_data`, так что твои товары и пользователи не пропадут при перезапуске контейнера.
* При локальном запуске файл создается прямо в папке `backend/larek.db`.
